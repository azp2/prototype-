# المنصور للاستشارات الهندسية

بروتوتايب عربي متجاوب لموقع شركة هندسية، يشمل التصميم والإشراف والمساحة والدفاع المدني، مع حركات ظهور وتمرير، تفاصيل خدمات ومشاريع تفاعلية، ونموذج تجهيز طلب عبر واتساب.

## التشغيل المحلي

من مجلد الملفات:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ثم افتح http://localhost:4173 . الموقع لا يحتاج إلى تثبيت حزم أو خطوة بناء.

## إعداد واتساب

أضف رقم الشركة بصيغته الدولية دون `+` في `config.js`:

```js
window.SITE_CONFIG = { whatsappNumber: "9665xxxxxxxx" };
```

استبدل المثال برقم حقيقي. عند غياب الرقم تعرض الأزرار رسالة توضيحية. فتح واتساب يجهز رسالة فقط؛ يراجع الزائر الرسالة ويرسلها بنفسه.

## الملفات

- `index.html`: محتوى الموقع والتصميم الأساسي.
- `enhancements.css`: التحسينات المرئية والحركات والتجاوب.
- `app.js`: التفاعلات، حركات JavaScript، وتجهيز رسائل واتساب.
- `config.js`: إعداد رقم واتساب.

الصور الخارجية عبر Unsplash والخط عبر Google Fonts. الصور والمشاريع تصورات توضيحية وليست سجل أعمال منفذة. يدعم الموقع تفضيل تقليل الحركة.
